بناء تطبيق مستر علاء APK من GitHub بدون Android Studio

1) أنشئ/افتح مستودع GitHub.
2) ارفع كل ملفات المشروع ومجلد .github/workflows.
3) افتح Actions.
4) اختر Build Android APK ثم Run workflow.
5) بعد ظهور علامة خضراء، افتح نتيجة البناء وانزل إلى Artifacts.
6) نزّل Mr-Alaa-Student-Accounts-APK وفك الضغط لتحصل على app-debug.apk.

إذا كان المستودع يحتوي على الإصدار السابق:
- استبدل محتويات المستودع بمحتويات هذا الإصدار، أو حدّث الملفات مع الحفاظ على مسار workflow.
- لا ترفع بيانات الطلاب أو ملفات JSON الاحتياطية إلى مستودع GitHub.
- بعد البناء، صدّر نسخة JSON من التطبيق القديم، ثم ثبّت الجديد واستورد الملف.

ميزة التحصيل متعدد الشهور:
تاريخ الاستلام منفصل عن شهر الاستحقاق. حدد شهر نوفمبر وديسمبر مثلاً، واكتب تاريخ استلام 1 ديسمبر والمبلغ 400 جنيه. سيقسم التطبيق المبلغ على الشهرين حسب المتبقي، من الأقدم للأحدث.

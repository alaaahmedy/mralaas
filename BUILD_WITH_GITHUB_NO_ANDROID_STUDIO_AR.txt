بناء APK بدون Android Studio أو كمبيوتر — باستخدام GitHub Actions

المتطلبات: حساب GitHub مجاني + متصفح موبايل.

1) افتح https://github.com وأنشئ حساباً أو سجّل الدخول.
2) اضغط + ثم New repository.
3) اسم المستودع: mr-alaa-student-accounts
4) اختر Public (حتى تعمل GitHub Actions بسهولة) ثم Create repository.
5) افتح المستودع، اضغط Add file ثم Upload files.
6) فك ضغط MrAlaaStudentAccountsAndroid_Source.zip على جهازك أولاً، ثم ارفع كل محتويات مجلد المشروع إلى المستودع، بما فيها المجلد المخفي .github. إذا لم يظهر .github عند الرفع، أنشئه يدوياً من Add file > Create new file واكتب المسار:
   .github/workflows/build-apk.yml
   ثم الصق محتوى الملف الموجود في الحزمة.
7) اضغط Commit changes.
8) افتح تبويب Actions في المستودع. اختر Build Android APK ثم Run workflow.
9) انتظر حتى تصبح المهمة خضراء (نجاح).
10) افتح نتيجة التشغيل، وانزل إلى Artifacts، واضغط Mr-Alaa-Student-Accounts-APK.
11) نزّل ZIP وافتحه؛ ستجد app-debug.apk. اضغط APK وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

ملاحظات:
- GitHub يبني APK تلقائياً على خوادمه؛ لا تحتاج Android Studio أو كمبيوتر.
- المستودع Public يعني أن ملفات كود التطبيق ستكون عامة. لا ترفع بيانات طلاب حقيقية أو ملفات النسخ الاحتياطية إليه.
- هذا Debug APK للتثبيت والتجربة، وليس إصداراً منشوراً على Google Play.
- بيانات الطلاب تبقى محلية داخل التطبيق. استخدم ميزة تصدير JSON لنقلها للهاتف الجديد.

التحديث الجديد: رسوم شهرية مستقلة لكل طالب، سجل تاريخي لتغييرات الرسوم، وتنبيه داخل التطبيق وإشعار Android عند فتح التطبيق بعد دخول شهر جديد مع وجود مبالغ غير مسددة. يجب الموافقة على إذن الإشعارات في أول تشغيل.
